## Summary

OpenAI describes evaluations as a pre-deployment check: establish what a model
can do, then use that evidence to determine which safeguards are required. Its
ExploitGym example focuses on whether a model can find and exploit software
vulnerabilities, making cybersecurity capability something to measure rather
than assume.
